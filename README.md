# SimplePythonDBconnect

A clean, ready-to-use Python starter template for **SQLite** database operations using the built-in `sqlite3` module.

## Features

* Pre-configured connection to a local `database.db` SQLite file.
* Automatic `users` table initialization (`id`, `username`, `age`, `created_at`).
* Parameterized `INSERT` and `SELECT` query boilerplate (SQL injection safe).
* Interactive CLI input and output template.

## Requirements

* Python 3.x (standard library only, no external packages needed)

## Quick Start

```bash
git clone [https://github.com/Yakyi/SimplePythonDBconnect.git](https://github.com/Yakyi/SimplePythonDBconnect.git)
cd SimplePythonDBconnect
python main.py
```
